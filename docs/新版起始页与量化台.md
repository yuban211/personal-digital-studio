## 一、这次做了什么

### 1. 起始页换成青柠式布局（limestart 风格）

- 全屏壁纸 + 轻微压暗，前景白字半透明玻璃控件，圆角大、阴影软
- 中央：大号时钟 / 日期 / 周数 → 胶囊搜索框 → 分类标签 → 收藏网格 → 页脚
- 右侧：可折叠便签（自动保存）
- 右下：设置抽屉（壁纸 / 模糊 / 压暗 / 搜索引擎 / 显示开关 / 分类管理 / 导入导出）
- 强调色 `#70c000`（青柠绿），与 limestart 一致

第三方能力全部换成自己的实现：

| 原站能力 | 原实现 | 现在 |
| --- | --- | --- |
| 搜索 | 各家联想接口 | 只做跳转 + 本地历史/收藏联想，不加载对方脚本 |
| 快捷方式 | 站点自带云同步 | 自己的 SQLite（`bookmarks` 表），本地缓存兜底 |
| 便笺 | 云同步 | localStorage，无外发 |
| 壁纸 | 图床外链 | 6 套 CSS 渐变 + 本地上传（存浏览器，不外传） |
| 天气/热榜 | 第三方 API | 未接入（页面不加载任何外部资源，`verify-static.py` 会拦截外链） |
| 字体图标 | CDN | 系统字体 + 字符图标 |

### 2. 收藏夹：增删改 + 分类整理

- 后端：`bm_categories` / `bookmarks` 两张表，schema 升到 v2，旧库自动升级
- 接口：`/api/library`、`/api/categories`(CRUD+reorder)、`/api/bookmarks`(CRUD+reorder+move+hit)、
  `/api/library/export|import`
- 交互：单击打开（记一次点击）、右键菜单（打开/编辑/置顶/换分类/删除）、
  拖拽排序、拖到分类标签上换分类、网格末尾「+」新增
- 安全：`javascript:`/`data:`/`file:` 等伪协议一律拒绝（收藏可导入，必须防 XSS）
- 删除分类默认只解绑不删收藏；`?cascade=true` 才连带删除

### 3. 全 A 行情 + 模拟实盘（独立页面，东财视觉）

- `services/quant`，FastAPI + SQLite，端口 9113，页面在 `/`
- 行情：腾讯公开接口为主（约 4600 只沪深主板+创业板），东财 `push2` 为备（可补科创板/北交所）
- 指数 6 条、行业板块 31 个、涨跌分布、全 A 分页表（14 列，可排序/筛选/搜索）
- 个股详情抽屉：当日分时（价格线 + 均价线）+ 手动买卖
- 模拟账户：纸上撮合，T+1、100 股整手、佣金万 2.5（最低 5 元）、
  过户费 0.001%、卖出印花税 0.05%、滑点 5bp、涨跌停不成交
- 策略引擎：内置 20 日动量 / 5-20 金叉 / 放量突破三个策略，
  外加 `strategies/` 目录热加载（丢 .py 进去 10 秒内出现在下拉里，无需重启）
- **你写在 `services/market/app/strategy.py` 的主板突破策略已接进来**：
  `strategies/user_breakout.py` 是适配器，复用你的 `StrategyConfig` 与
  `is_main_board_symbol`，规则口径一致（20 日高 / MA20>MA60 / 量比 1.2 / 3×ATR 止损 /
  前 10 日低止损 / 0.5% 风险预算 / 20% 单票上限）。
  唯一差异：回测是次日开盘成交，实盘引擎按最新价成交（引擎没有订单簿）。
- 净值曲线、持仓、成交记录、风控参数（止损/止盈/单票仓位/持仓上限）

## 二、本地怎么跑

```bash
# 起始页（9103）
cd src
APP_SECRET=dev PYTHONPATH=. python -m uvicorn app:app --port 9103

# 量化台（9113）
cd services
PYTHONPATH=. python -m uvicorn quant.app.api:app --port 9113
```

打开 <http://127.0.0.1:9103/>，右上「行情」按钮进量化台。

> 起始页里「行情」按钮用的是相对路径 `quant/`，
> 所以上线时量化服务要挂在 `<前缀>/quant/` 下（见下）。

## 三、上线到雨云

1. 上传：`src/static/home/`、`src/{db,repo,app}.py`、`services/quant/`（含 `wheels` 不需要）
2. Caddyfile 增加两段（顺序敏感，`handle_path` 越长越靠前）：

```caddy
handle_path /studio/quant/* {
    reverse_proxy 127.0.0.1:9113
}
handle /studio/* {
    reverse_proxy 127.0.0.1:9103
}
```

3. 起量化服务（面板单行命令）：

```
cd /workspace/services && PYTHONPATH=. python3 -m uvicorn quant.app.api:app --host 127.0.0.1 --port 9113
```

4. 重启面板 → 访问 `/studio/`（新起始页）、`/studio/quant/`（量化台）

回滚：起始页把 `src/static/web/` 的旧版恢复为主入口即可（`app.py` 里 index 找不到
`home/index.html` 会自动回退到 `web/index.html`），Caddy 删掉 `handle_path` 那一段。

## 五、已知限制

- 腾讯 `aStock` 榜不含科创板/北交所；东财可用时会自动补齐，不可用时只有沪深主板+创业板
- 盘中日线缓存当天不刷新（策略用的是日线形态，影响可忽略）
- 非交易时段默认允许撮合（`QUANT_OFFHOURS=0` 可关闭），页面顶部有明确标注
- 模拟盘不做除权除息调整、不模拟盘口深度与排队
