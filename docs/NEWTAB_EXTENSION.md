# 浏览器首页扩展方案

## 目标

把「个人数字工作室」做成浏览器**新标签页**，即打开新标签时自动展示工作室首页。

## 技术路径（已实测验证）

**Chrome Manifest V3 扩展 + `chrome_url_overrides.newtab`**

### 实测证据（2026-10-28）

在星愿浏览器（Twinkstar 10.13，Chromium 128 内核）上实测：

1. `--load-extension` 加载扩展成功
2. 弹出确认框：「此网页被扩展程序 "Studio NewTab Probe" 更改了」
   → 证明扩展已被识别，且 `chrome_url_overrides.newtab` 生效
3. 点击「保持现状」后，新标签页直接显示扩展页面
4. 扩展图标出现在工具栏

### 为什么用扩展而不是其他方案

| 方案 | 可行性 | 原因 |
|---|---|---|
| **Chrome 扩展** | ✅ 已验证 | 星愿支持扩展；可离线打包；不依赖 CDN |
| 改注册表 `homepage` | ❌ | 星愿的 `PreferenceMACs` 对偏好值做了 MAC 保护，手改无效 |
| 浏览器「设置 → 主页」手动填 | ⚠️ 可行但脆弱 | 只能填一个 URL，丢失全部交互能力 |
| 装 NewTab Redirect 类扩展 | ❌ | 多一层依赖，且只是跳转不是真正接管 |

### 关键约束

- **必须离线可用**：本机所有 CDN 均不可达（jsdelivr/unpkg/cdnjs/npmmirror 全部失败），
  扩展内不得引用任何外部资源
- **MV3**：星愿内核 128，只支持 Manifest V3
- **不需要后端**：数据从线上 studio 服务拉取；拉取失败时降级为静态内容

## 架构

```
studio-newtab/
├── manifest.json        MV3 清单
├── newtab.html          页面骨架
├── newtab.css           样式（沿用站点设计令牌）
├── newtab.js            逻辑（数据拉取 + 交互）
├── icons/               图标
└── README.md            安装说明
```

### 页面模块

复用站点已有的组件与视觉：
- 顶部：品牌 + 实时时钟 + 在线状态
- 主区：天气场景卡（Canvas）、音乐播放器、图片轮播
- 侧栏：项目列表、日志列表

### 数据来源

| 数据 | 来源 | 降级 |
|---|---|---|
| 天气 | `/studio/` 页面的 JSON 接口 | 标注「离线」 |
| 项目 / 日志 | 同上 | 显示空态 |
| 图片 | 媒体库 | 显示占位 |

## 安装（开发者模式）

1. 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择 `studio-newtab/` 目录
5. 新开标签页即可看到
