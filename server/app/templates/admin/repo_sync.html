CONVENTION

仓库里怎么放

把 Markdown 放进这两个目录，同步时会被自动识别：

content/
├── projects/
│   └── garden-action.md
└── posts/
    └── my-note.md

文件开头写 front-matter（可选，但推荐）：

---
title: 标题
slug: url-friendly-slug
summary: 一句话摘要
status: 已上线
tags: 标签1, 标签2
date: 2026-01-01
draft: false
---

没写 summary 时会取正文第一段；没写 slug 时会从标题生成。

同步只读取 Markdown 文本，不会执行仓库里的任何代码。
